# sbpwithbot

SBP Prize Bond website with an integrated chatbot backend.

## Project layout
- `PrizeBondApp.jsx`, `src/`, `public/`, `index.html`: website
- `Bot/PrizeBondChatBot/`: chatbot backend and knowledge base

## Local run
- Website: `npm install` then `npm run dev`
- Bot: run the Flask server inside `Bot/PrizeBondChatBot`
